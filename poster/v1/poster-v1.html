The loop: the model writes, tools decide

A fix that corrects one wrong assumption usually leaves the same assumption at other sites. The agent reads each past fix and writes inputs aimed at those sites, after AFuzz [4]; tools build, judge, reduce and deduplicate, and discard almost everything it writes.

What we do not claim

No maintainer has confirmed these bugs; none is filed until a named author approves.
43 of 187 seeds ran, 3.6 an hour under Vertex rate limits: the list is not exhaustive.
Inside the loop, CHIA's repair chain reached one patch: a debug print. We claim no fix from it.
The loop finds crashes and assertion failures; the wrong-output oracle (6 of 187 seeds) only reports.

Controls

One experiment. Both arms share harness, oracles, reducer and gate. The mutation arm rewrites seed tests syntactically, after Mut4All [3], without the diff or the root-cause class.

Pre-registration. Every threshold sits in one budget file, registered by an annotated git tag. The loop refuses an untagged file and mutators committed after the tag.

Deduplication. One bug when primary fingerprints match. On 22 hand-labelled pairs:

Known issues. GitHub stops paginating at page 100, so the mirror walks both directions and unions them: 2,652 issues.

Contamination. The model may have memorised later fixes. A symbol-level screen flags 77% of the corpus (96% at file level); a flag marks a candidate, never drops it.

Fifteen new bugs, twelve root causes, thirteen patches

Each of the 15 reproduced on another worker, was minimal at the reducer's fixpoint, was valid input, and matched no issue and no commit since the pin. Re-checked on CIRCT main of 26 October (4738bd2), all 15 still fail as the same bug: 8 with the same fingerprint, 7 with only source lines moved. Of 277 issues and PRs since 16 September, none reports or fixes them; #11141, #11142 and #11267 are related, not the same.

What the gate missed, found after review

18 seeded probes booked as the model's fault were compiler bugs: each input parses and verifies, then the pass emits invalid IR. 4 are other symptoms of root causes 07, 08 and 12, and those patches fix them. 14 show three new root causes, unpatched and not yet shown reachable from a frontend:

firrtl-flatten-memory SInt memory with a multi-bit mask (5)
firrtl-infer-domains a domain used inside firrtl.when (3)
synth-lower-word-to-bits lowering inside func.func (6)
Mutation, given its whole window

A post-review run wrote 115,869 mutants in 11.1 h; 34% reached the pass they target. 45 fired the oracle and 27 passed the gate: 3 fingerprints, 2 root causes, neither among the 15:

FIRRTLOps.cpp segfault in RWProbeOp::verifyInnerRefs (16)
-hw-memory-sim takes i0 clock and enable ports on trust (11)

The gate dropped 14 more as fixed after the pin; they still crash on main, likely a third bug.

Take it. Every input, verdict, reduced case, transcript and gate decision is in the repository and its data release data-2026-09-25. The loop ships as CHIA nodes and tools meeting at a frozen contract of seven record types, with 739 tests, 689 needing no cluster, network or model. Upstream to CHIA: the assertions-on image and its build workflow (ucb-bar/chia#117) and three CIRCT helpers (#118); the repair-backend branch is not yet submitted.
