1. Task Overview

Supply is not scarce in LLVM/CIRCT: 82 label:bug issues filed in a year, 65 closed; the backlog is 101 open, median age 911 days. Attention, not supply, binds. Yet every past fix names a root-cause class with latent siblings, in a compiler with no in-tree fuzzing infrastructure — and CHIA's circt_issue_solver today consumes open issues and only reads.

We mine that history into seeds: 187 bug-subject fix commits over 24 months, 171 rebuildable from an exact prebuilt LLVM SDK. Each seed's lit RUN: line fixes the language of the inputs generated from it, and the assertions CHIA's image compiles out become the oracle. A CHIA loop seeded with 187 mined CIRCT fix commits, 171 with an exact prebuilt SDK: it generates inputs in each seed's own language, catches them with assertions CHIA's image compiles out, reduces, repairs, gates every filing.

Key Architectural Innovations
  • Seeded generation: AFuzz's method on a pin-verified corpus. Per seed the agent reads the diff and test, states the root-cause class, names sibling sites. Input language follows the seed — its lit RUN: line is the template: circt-opt plus a pass pipeline, firtool, or circt-verilog.
  • Assertions restored: Under CHIA's flags 620/620 CIRCT object compile commands carry -DNDEBUG. -UNDEBUG restores them: 605/605 targets link, 495/513 objects reference __assert_fail. MLIR/LLVM-core assertions stay off; a segfault rooted there is report-only.
  • Release-pinned main + image family: Runs on the newest main whose LLVM pin has a release SDK: 171 of 187 seeds exact, 38 images. One bump off is a hard tblgen failure. Lag: 16 of 63 windows never released, worst 100 commits / 16 d, median release latency 3.3 d.
  • Gate + head-to-head evaluation: Only maintainer-confirmed bugs count. The budget is pre-registered by a commit to the loop repository before the campaign. Two arms, equal budget, identical tools, oracles and gate: seeded agent versus mutation fuzzer. Gate precision = accepted / filed. Zero is reportable.

3. Expected Results
  • Headline metric: distinct, maintainer-confirmed bugs within the pre-registered budget, seeded arm versus mutation arm. Confirmed = maintainer label, comment or upstream fix; oracle agreement alone = candidate.
  • Secondaries: candidates before and after dedup, reports filed, gate precision = maintainer-accepted reports / reports filed, repairs merged; seeded-bug validation reported separately.
  • Instrument: 171 buildable tasks, 38 images, and the assertions-on image — mergeable into CHIA's Dockerfile.
  • Composable CHIA blocks: report-supply node, assertions-on image builder, reduce block, gate block, open-sourced.
  • Honest scope: zero is reportable; arcilator-versus-Verilator divergences are report-only; no filing at volume; nothing has run end to end yet.
