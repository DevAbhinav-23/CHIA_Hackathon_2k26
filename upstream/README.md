The fix round wires that staging; until it lands, only `sync-to-chia.sh` applies them, and it applies `issue_task-vertex-branch.patch` alone. `circt_bug_loop/tests/test_upstream_patches.py` holds both patches applying at commit 16c35e92 and the two behaviours the vertex patch exists for.
